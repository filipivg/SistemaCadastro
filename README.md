# SistemaCadastro
Atividade Prática - Controle de Versão e Gerenciamento de Mudanças com Git.
## Respostas

### Questão 1
Permitir trabalhar em alterações do projeto de forma separada, sem afetar diretamente a branch principal.

### Questão 2
Commit registra uma alteração no projeto. Merge junta as alterações de uma branch em outra.

### Questão 3
Para identificar facilmente o que foi alterado em cada commit.

### Questão 4
Porque permite controlar as alterações, trabalhar em equipe e recuperar versões anteriores do projeto.

### Questão 5
Representa uma nova versão do sistema, marcada através de uma tag no GitHub.

### Questão 6
Tag pelo terminal:

```bash
git tag -a v1.1.0 -m "Versão 1.1.0"
git push origin v1.1.0
